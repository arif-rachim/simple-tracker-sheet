Labels: type and press Enter or , to add, or pick an existing one. Use type:value (e.g. status:open) for typed labels: an issue holds one value per type, so adding status:closed replaces status:open. Click a label to filter by it. Label filters of the same type match any of them; different types must all match.
Data is saved in this browser automatically. Editing requires the PIN.
